# 六月息插件开发指南

插件 = 一个文件夹（放进 `plugins/` 或用户插件目录），核心是一个 `manifest.json` 声明身份，`routes.py` 提供后端路由。

## 快速开始

1. 复制 `docs/plugin-template/` 为 `plugins/myplugin/`
2. 改 `manifest.json` 的 `id`/`name`/`desc`（id 必须小写字母开头，2-40 字符）
3. 重启 JuneXi —— 你的插件出现在「插件」管理页
4. 开发友好：改动 `routes.py` 只需重启；前端 assets 可强刷

## manifest.json 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| id | ✓ | 唯一标识，小写字母/数字/中划线。同名用户插件覆盖内置 |
| name / desc / version | ✓ | 展示信息 |
| routes | ✓ | `"routes.py:bp"` —— 加载器 import 该文件并取 `bp`（flask.Blueprint）注册 |
| enabled | | 默认 true；开关由用户在管理页控制，写 `plugin-overrides.json` |
| nav | | `{tab,label,icon}` —— 注入顶部导航栏 tab 按钮（插在"插件"tab 前）。点击触发 `switchTab(tab)`；目标页面 div 可由核心模板提供或插件自行注入 DOM。禁用/卸载插件后 tab 自动消失 |
| assets | | `{css:[],js:[]}` —— 插件 `static/` 下的文件注入全站 |
| warmup | | `"warmup.py:run"` —— 启动时立即执行（预连接/预热） |
| permissions | | 声明权限：`network`（外链请求）/`files`（读写用户文件）/`none`。市场页显示给用户看 |

## 后端约定

- 路由全部挂 `@bp.route(...)`，不要新建 Flask app
- 用 `_core("_log_activity")` 记足迹、`OBSIDIAN_VAULT` 等核心配置——**不要 `from app import ...`**（循环 import），惰性取保持解耦
- 插件之间不互相 import；跨插件数据走 HTTP 内部端点（如 CBDB 插件的 `/api/cbdb/_counts`）
- 路由命名建议 `/api/<插件id>/...`，避免撞车

## 导航注入（nav）

manifest 写 `"nav": {"tab": "mytab", "label": "我的插件", "icon": "🔬"}` 后，启动时前端自动把 tab 按钮插进导航栏（"插件"tab 之前）。两种页面模式：

1. **页面 DOM 在核心模板**（如读文献页）：核心提供 `<div id="mytab" class="page">`，nav 只负责 tab 按钮。适合与核心深度耦合的页面
2. **页面 DOM 插件自建**：用 assets 机制注入 JS，JS 在 DOMContentLoaded 时创建 `<div id="mytab" class="page">` 并填充内容。完全自治

插件被禁用或卸载后，tab 自动消失（loader 在收集 nav 前就跳过禁用插件）。

## 用户数据存储

插件的用户配置/缓存放 `%LOCALAPPDATA%\JuneXi\<插件id>\` 或 `%LOCALAPPDATA%\JuneXi\<插件id>.json`（参照 acad-feed 的 `acad_feed_sources.json` 自定义源模式）。不要写 `_MEIPASS` 安装目录（只读且升级即丢）。

## 打包发布

1. 文件夹打成 zip（zip 根 = 插件文件夹本身，内含 manifest.json）：
   ```powershell
   Compress-Archive -Path myplugin -DestinationPath myplugin.jxplugin
   ```
2. 本地测试：管理页「📦 安装新插件」→ 从本机安装
3. 发布：把 zip 传到你的 Release，算 SHA-256（`Get-FileHash myplugin.jxplugin -Algorithm SHA256`）
4. 向 junexi 仓库的 `plugins-registry.json` 提 PR，加一条目（id/name/version/desc/author/url/sha256/permissions），审核通过即上架市场

## 安全红线

- zip 安装有路径穿越防护，manifest 必须合法
- 别在插件里跑 `eval`/`exec` 外部输入；别静默外传用户数据——市场页会显示你的 permissions 声明，用户据此决定信不信
